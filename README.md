# SICE-CBA • Sistema Integral de Control y Evaluación
### U.E.P. Colegio Bellas Artes — Maracaibo, Venezuela (Año Lectivo 2026-2027)

[![Deploy to GitHub Pages](https://github.com/themiguedev/SISCEBA/actions/workflows/deploy.yml/badge.svg)](https://github.com/themiguedev/SISCEBA/actions/workflows/deploy.yml)

SICE-CBA es la plataforma integral de gestión curricular, planificación docente, evaluación multidimensional y comunicación pedagógica institucional, desarrollada para sustituir definitivamente al antiguo sistema SEO ante las exigencias tecnológicas contemporáneas.

## 📚 Estructura Curricular y Módulos

### 1. Planificación Pedagógica
* **Áreas de Formación y Perfiles:**
  - **Inicial:** Formación personal, Componentes del ambiente, Artes Plásticas, Música, Ed. Física, Ajedrez, Natación, Inglés, Informática y Desarrollo Humano.
  - **Primaria:** Lenguaje, Matemáticas, Ciencias Naturales, Ciencias Sociales, Ed. Estética (Plástica y Música), Ed. Física, Robótica, Finanzas, Diseño Creativo y áreas integradas.
  - **Media General:** 14 Áreas regulares y 10 integradas (incluyendo Robótica, Inteligencia Artificial, Artes Gráficas, Proyecto de Vida y Creación Literaria).
* **Bancos de Competencias e Indicadores:** Creación, edición y transferencia inter-períodos.
* **Bancos de Estrategias Didácticas y de Evaluación.**
* **Planes Quincenales y Planes de Lapso:** Flujos de aprobación (*Borrador*, *En Revisión*, *Definitivo*).

### 2. Evaluación Integral
* **Evaluación Diagnóstica:** Con módulo especializado de Robótica en Educación Inicial.
* **Evaluación Procesal Continua:** Registro cualitativo (*C / EP / I*) para Inicial y Primaria, y escala numérica (*01 - 20*) para Media General.
* **Evaluación Final de Lapso:** Cierre de calificaciones y consolidación estadística.
* **Cuadros y Gráficos Estadísticos:** Distribución de notas, promedios por área y porcentajes de consolidación.

### 3. Comunicación, Reportes y Asistente IA
* **Boletines Informativos Oficiales:** Listos para impresión formal en alta fidelidad (`@media print`).
* **Actas de Consejo de Curso:** Con quórum docente y firmas institucionales.
* **Planes de Acción Personalizados con IA:** Detección predictiva de brechas cognitivas y generación de hojas de ruta pedagógicas individualizadas.
* **Reportes Institucionales:** Planes remediales, alumnos a revisión y materias pendientes.

## 🚀 Puesta en Marcha

### Prerrequisitos
* Node.js 18+ o superior
* npm

### Instalación y Ejecución
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo (puerto 3000)
npm run dev

# Compilar para producción
npm run build

# Previsualizar build de producción
npm run preview
```
