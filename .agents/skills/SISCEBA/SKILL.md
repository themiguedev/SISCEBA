# Skill: SISCEBA - Sincronizacion con GitHub

Esta skill automatiza el flujo completo de control de versiones y sincronizacion del proyecto con el repositorio remoto institucional:
- **Repositorio Remoto**: https://github.com/themiguedev/SISCEBA
- **Rama Principal**: main

## Flujo de Trabajo
1. Revisar estado de los cambios con git status.
2. Agregar los archivos modificados y creados con git add .
3. Crear un commit con mensaje descriptivo y conciso.
4. Subir los cambios a la rama principal mediante git push origin main.
5. Confirmar el hash resultante y el estado de la sincronizacion.
